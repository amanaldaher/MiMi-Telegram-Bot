An interactive asynchronous Telegram bot built with Python 3 and the python-telegram-bot (v20+) library. MiMi Bot serves as an interactive digital portfolio and networking hub, allowing visitors on Telegram to explore skills, browse key projects, review professional bio details, and access direct social links through responsive inline keyboard menus.

This project serves as a showcase of my back-end development skills, bot automation workflows, and software integration interests as an IT Engineering student.

## 📌 Features

- **Asynchronous Architecture:** Built using modern `async/await` patterns with `ApplicationBuilder` for optimal responsiveness and event handling.
- **Interactive Inline Keyboards:** Intuitive button navigation (`InlineKeyboardMarkup`) eliminating the need to type manual commands.
- **Dynamic Portfolio Sections:** Comprehensive menus covering About Me, Technical Skills, Highlighted Projects, Social Links, and Direct Contact.
- **Security-First Configuration:** Secures the bot API token using environment variables (`python-dotenv`) and strict `.gitignore` rules to prevent credential leakage.
- **Lightweight & Fast:** Modular architecture built cleanly without bloated frameworks or unnecessary external overhead.

<hr>

## 🛠️ Built With

- **Python 3.x:** Core application logic and asynchronous scripting.
- **python-telegram-bot:** Asynchronous framework for interacting with the Telegram Bot API.
- **python-dotenv:** Secure configuration management via isolated `.env` environment files.

## 💻 How to Run Locally
Clone the repository:

Bash
git clone https://github.com/amanaldaher/MiMi-Telegram-Bot.git
Navigate to the project directory:

Bash
cd MiMi-Telegram-Bot
Set up environment variables:

Create a .env file in the root directory and add your bot token:

Plaintext
TELEGRAM_BOT_TOKEN=your_bot_token_here
Install dependencies and run:

Bash
pip install -r requirements.txt
python bot.py
